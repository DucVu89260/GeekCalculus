# GeekCalculus API

Laravel 12 API cho dự án kết cấu và danh mục Anh–Việt. Giao diện chính nằm ở
`../../frontend/vue`; không có ứng dụng frontend riêng trong thư mục Laravel.

Xem [hướng dẫn chạy local, schema và API](../../README.md).

Chạy kiểm thử từ thư mục `structural-platform`:

```sh
docker compose run --rm --no-deps backend php artisan test --compact
```
