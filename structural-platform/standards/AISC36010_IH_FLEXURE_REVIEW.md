# AISC 360-10 I/H flexure F4 source review

## Source and supported branch

The source is ANSI/AISC 360-10, June 22, 2010, supplied PDF SHA-256 `f9b15004cf51dbaec6c06588d81aa5256be268af87906e5ba863c289795f4e99` (612 physical PDF pages). F4 scope is printed pages 16.1-49 through 16.1-53, physical pages 105-109. Equations F4-1 through F4-16 are on physical pages 106-109. F4-11 was visually checked on physical page 108 / printed page 16.1-52. Its `h` symbol means clear web distance and `d` means overall depth; for this symmetric welded section `h=hc=d-2tf`. The code equation is

`rt = bfc / sqrt(12[ho/d + (aw/6) h^2/(ho d)])`.

The same page's boxed user note gives a conservative approximation; the implementation uses the actual F4-11 equation. F4-8 was visually checked on physical page 107 / printed page 16.1-51 and uses the nested square root `Lr = 1.95 rt(E/FL)sqrt(q + sqrt(q^2 + 6.76(FL/E)^2))`, `q=J/(Sxc ho)`.

The implementation in `aisc360-10-ih-flexure.mjs` covers a doubly symmetric sharp-corner built-up I/H with equal rectangular flanges, web attachment at the inside flange faces, and a noncompact web. It consumes canonical Sx, Zx, Iy and J from the shared geometry core; it computes only F4's compression-flange inertia Iyc=bfc³tfc/12 for the Iyc/Iy ratio. It evaluates compression flange yielding (F4-1), LTB (F4-2 or F4-3/F4-5), and compression flange local buckling (F4-13 or F4-14), then reports their minimum nominal strength in kN·m. It returns no ASD/LRFD factor. F4-15/F4-16 tension flange yielding is inapplicable to this symmetric gross section.

Rolled shapes are blocked because the actual fillet/corner radius and clear-web geometry are not represented. Cover plates, channel caps, unequal-flange/singly symmetric shapes, bolted web attachments with fastener-line clear depths, flange holes, tension rupture, shear, stiffeners, axial interaction and overall member compliance are outside this module. The caller supplies a source-traceable F1-1 Cb when Lb>Lp; J is needed only for that LTB branch when Iyc/Iy>0.23. F4 does not use Cw.

## Independent expected fixture

The fixture uses `h=800`, `bf=320`, `tf=16`, `tw=7` mm, `Fy=345`, `E=200000` MPa, and a built-up welded sharp-corner section. Component integration gives `hc=768` mm, `ho=784` mm, `Sx=4,594,947.413333 mm3`, `Zx=5,046,272 mm3`, `Iy=87,403,285.333333 mm4`, and `Iyc=43,690,666.666667 mm4`; hence `Iyc/Iy=0.499874421196`. The canonical open-section thin-wall torsion sum is `J=(2bf tf^3 + ho tw^3)/3=963,450.666667 mm4`.

The independent hand calculation gives `hc/tw=109.714285714`, `lambda_pw=90.530161521`, `lambda_rw=137.239872518`, `aw=1.05`, `rt=86.345141389 mm`, `Lp=2,286.841371307 mm`, `Lr=8,152.511172249 mm`, `kc=0.381881308`, `lambda_f=10`, `lambda_pf=9.149324835`, `lambda_rf=16.894456939`, `FL=241.5 MPa` and `Rpc=1.057881244`.

For `Lb=2,000 mm`, LTB does not apply. The F4-1 capacity is `1,677.013495962 kN·m`; F4-13 gives `1,614.701235965 kN·m` and governs. For `Lb=5,000 mm`, F4-2 governs at `1,414.593966067 kN·m`. For `Lb=10,000 mm`, F4-3/F4-5 gives `Fcr=166.485738305 MPa` and governs at `764.993212582 kN·m`. The test asserts these fixed values at relative tolerance `1e-9`; expected strengths are not generated by the implementation.

The separate test geometry helper derives only canonical plate properties for modified boundary fixtures. It does not calculate expected F4 strengths.

## Existing F2/F3/F5/F6 source comparison

The F2, F3 and F5 strength equations and classification branches in `aisc360-10-verified-hi.mjs` match F2-1 through F2-7, F3-1/F3-2 and F5-1 through F5-9 for the supported doubly symmetric sharp-corner model. F2 uses `c=1`, as F2-8a specifies for doubly symmetric I shapes. F5 uses `hc²` in F4-11's numerator term; this is correct because the AISC `h` symbol denotes the clear web distance, which equals `hc` for this welded symmetric shape. F6-1 through F6-4 also match the I-shape minor-axis equations, including `b=bf/2`. No source equation transcription defect was found in these branches. These are source comparisons, not independent validation of every branch's numerical outputs.

No formula transcription defect was found in F2/F3/F5/F6. Rolled-section results in the existing kernel remain approximate because its sharp-corner dimensions and geometric properties omit profile fillets. The kernel surfaces that warning; rolled-shape values should not be treated as exact profile results without catalog geometry. Built-up `hc=d-2tf` is appropriate for welded attachment at the flange inside faces; bolted sections need the nearest fastener-line dimension instead.

## F13.1 flange-hole relation

F13.1 is printed page 16.1-64 / physical PDF page 120 and was visually checked. It applies to rolled or built-up shapes and cover-plated beams with tension-flange holes proportioned on gross-section flexural strength. In addition to the other Chapter F limit states, when `Fu Afn < Yt Fy Afg`, it caps nominal flexural strength at `(Fu Afn/Afg)Sx`; otherwise the F13.1 rupture limit state does not apply. Here `Afg/Afn` follow B4.3 and `Yt=1.0` for `Fy/Fu<=0.8`, `1.1` otherwise. This is an additional cap at the hole location, not an F4 web/flange classification change. H4 separately checks combined axial force and major-axis flexure at those holes.
