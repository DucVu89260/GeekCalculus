# Vue scope

Inherits [root instructions](../../../AGENTS.md). Start from [the actual module map](src/modules.js), [App](src/App.vue) and [ModuleHub](src/components/ModuleHub.vue).

- Preserve Loading → Steel Structure → RC Structure order, existing hash routes/aliases, VI/EN labels and native/demo behavior. Keep neutral geometry accessible from both Steel and RC.
- Use `src/api.js` for native authenticated JSON requests/CSRF. `src/demo-api.js` is a separate localStorage implementation; do not use demo success as a server-security check.
- Library UI: `LibraryBrowser.vue`; catalog geometry payloads: `src/sectional-properties/catalog-payload.js`; shared geometry display: `SectionPropertiesPanel.vue`/`SectionCalculatedProperties.vue`. Inspect the caller before adding another calculator/editor.
- Formula sources belong in `section-properties` or `standards`, not Vue templates or standalone HTML copies. `hi-section-properties.ts` adapts the shared core.
- Several existing tools are standalone files in `public/`, wrapped by Vue. In particular Combo Generator is an iframe with an explicit postMessage save/restore contract; preserve its existing matrix/export behavior.
- `docs/` at repository root is generated by Pages CI. Edit Vue/public source, not the published copies. Preserve `.geekcalculus-demo-build` protection in build tooling.
- Main currently has the monolithic pre-build script. PR #19 splits engine/browser/library targets. Inspect `package.json` and the builder on your branch; do not assume the pending flags exist on main.
- Do not fill missing private-source assets by copying supplied copyrighted PDFs into `public/` or `docs/`. Check authenticated source endpoints and artifact provisioning instead.

From this directory:

```sh
npm ci
npm run typecheck
npm test
npm run build -- --outDir /tmp/geek-vue-review --emptyOutDir
```

Choose a writable absolute output directory on your OS. For UI changes, use the relevant existing smoke from `structural-platform/tests`, with native private account fixtures when testing permissions/storage. Keep implementation-only diagnostics out of ordinary product flows unless useful to the user.
